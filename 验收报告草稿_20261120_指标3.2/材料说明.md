# 材料说明

|文件/文件夹|内容|
|---|---|
|验收报告草稿.md、验收报告草稿.pdf| 同一份报告草稿。|
|`导出材料/`| 保存指定运行的最新导出文件夹。|
|`固液联合任务验收流程说明/`|验收过程的数据流动方式解读，以更加清晰的展示项目原理和验收过程。其中的.md 和.pdf 是同一份文件. `images/`存储 markdown 撰写过程中保存到图片|
|`附件/`| 保存验收方案、指标 3.2 摘录、数值参考轨迹、参考视频索引、样本筛选记录及逐样本复核表。|
|`图片/`| 保存汇总报告草稿中所用图及。所有推理数值来自指定的本次导出结果(见下)。|

注:
- 流程说明中的示例、模型原理和“成功”表述作为送测方解释材料保留。正式指标结论以验收方案、原始证据及验收人员核验为准。本次补充的逐动作有效性和连续计数记录来源于送测方2026年11月20日的确认，验收方据实填写独立观测依据并签署。
- 本目录未包含程序代码和原始视频。
- 附件/连续片段统计.csv 为 50 条片段统计。原始导出中的推理、误差及评定文件保留原有内容。
