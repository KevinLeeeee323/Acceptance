# 扩展范围检查记录

- 使用 solid/measure_solid_0630 与 liquid/measure_liquid_full_0622 同编号数据。共同范围为 0–95。
- 首批检查 0–69（包含两端，共 70 条），不足时依次检查 70–79、80–89、90–95。
- 每条采用本次完整推理的六关节总体 RMSE 作判断，严格小于 0.1 rad 才合格。检查过程逐条保存，可以断点续跑。
- inspection.json 记录全部已检查条目的 RMSE、七项 RMSE、是否合格、耗时和错误。results/ 保存每条成功推理的 [7,3150] prediction、七项 rmse 和六关节 overall。
- 异常情况.json 记录推理失败及异常数值。数值异常观察阈值为关节 action 绝对值超过 100 rad、爪夹 action 绝对值超过 1 m，或总体 RMSE >=1 rad。是否入选仍以六关节总体 RMSE <0.1 判定。
- selected_samples.json 和 合格清单.csv 在凑齐 50 条后生成。从按编号升序排列的合格数据中用抽取种子 42 随机选出 50 条，再将入选编号升序排列并用排序种子 43 随机打乱，UI 每次加载全部 50 条并保持该顺序。
- 筛选结果保留当次模型输出，后续验收运行会重新推理并重新计算指标。

本次按更新后的规则，仅从前 70 条（编号 0–69）中选取。原先按 0–70 启动的检查额外完成了第 70 条，其结果保留在全部检查记录中，不参与最终选样。前 70 条中有 59 条合格，最终随机抽出 50 条。

本次抽取种子 selection_seed = 42，排序种子 order_seed = 43，分别写入 selected_samples.json 和 inspection.json。候选池为编号 0–69 中当次 RMSE <0.1 的 59 条数据，按编号升序组织。抽取算法为 random.Random(42).sample(候选池, 50)，排序算法为对升序入选编号执行 random.Random(43).shuffle。UI 按 ordered_ids 显示全部 50 条。入选条目的本次总体 RMSE 范围为 0.0421212611–0.0985971569 rad。

异常条目为 4、16、33、34、42，参考 action 中存在超过 100 rad 的异常点，详细关节、帧号和值见“异常情况.json”和“参考数据异常复核.json”。这些条目未入选。
