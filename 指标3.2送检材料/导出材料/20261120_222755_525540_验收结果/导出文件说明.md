# 验收结果文件说明

## 文件清单

本文件夹是一批固定清单数据的完整导出快照，旁边的同名 ZIP 包含相同内容。复制整个文件夹或 ZIP 即可保存本批验收记录。

| 文件 | 内容与用途 |
| --- | --- |
| batch_summary.json | 运行 ID、创建与导出时间、固定清单来源、有序样本名单、完成数、已确认评定数、成功数及成功率。files 字段保存其余文件的 SHA-256，供完整性核验。 |
| samples.csv | 按界面 Samples 顺序排列的样本清单，含原始条目编号、模型版本、推理与评定状态、异常标记、匹配点数、七项 RMSE 及六关节总体 RMSE。可直接用表格软件打开。 |
| results/episode_XXXXXX.json | 每条样本的数值推理结果，便于重新绘图、复算指标及后续分析。文件名使用原始数据集条目编号，补齐六位。具体结构见下文。 |
| plots/sample_XXX.png | 参考 action 与模型推理 action 的七维对比图，含原子动作底色及图例。文件名使用固定清单展示顺序，从 001 开始。 |
| 评定结果.json | 本批的逐条评定、备注与异常记录。items 的键为原始条目编号，choice 为 success 或 failure，confirmed 为 true 才计入已评定及成功率。notes 为整批备注，incidents 为逐条异常记录。未填写字段可能缺省。 |
| 备注.txt | 整批备注的纯文本副本，方便直接查看。 |
| 异常记录.json | 本批已填写的异常记录，包含现象、其他现象说明、原因、发生时间、处理人及跟进方式。records 的键为本批从 0 开始的位置，sample_id 为从 1 开始的样本序号，episode 为原始条目编号。发生时间 occurred_at 按北京时间精确到分钟，updated_at 为自动保存时间。 |
| 推理配置.json | 推理服务器硬件、软件版本、模型启动命令和配置核实日期。整批共用一份。 |
| 轨迹对齐方法.txt | 3150 个点的来源、动作段的采纳方式、左右臂映射和 RMSE 计算口径。 |
| 有效动作判据.csv | 原子动作名称、区间、描述和人工核验判据，供验收人员结合轨迹与视频核对。 |
| 导出文件说明.md | 本说明。 |

## results 中的 JSON 结构

每个 JSON 对应一条 Solid + Liquid 配对样本，包含以下三个字段。

| 字段 | 结构 | 含义 |
| --- | --- | --- |
| prediction | 7 行 × 3150 列的浮点数二维数组 | 第一维是关节／爪夹维度，第二维是按时间排列的帧。prediction[j][t] 表示第 j 个维度在拼接帧 t 的模型 action。j 从 0 开始。 |
| rmse | 长度为 7 的浮点数数组 | 各维度模型 action 与参考 action 在全部 3150 个对应帧上的 RMSE。顺序与 prediction 相同。 |
| overall | 一个浮点数 | 前六个关节 RMSE 的均方根，单位 rad。爪夹单独以 m 展示。 |

七行的顺序如下。

| 数组行 j | 界面标记 | 关节／爪夹 | 单位 |
| --- | --- | --- | --- |
| 0 | J01 | 腰关节 waist | rad |
| 1 | J02 | 肩关节 shoulder | rad |
| 2 | J03 | 肘关节 elbow | rad |
| 3 | J04 | 前臂旋转 forearm_roll | rad |
| 4 | J05 | 腕关节俯仰 wrist_angle | rad |
| 5 | J06 | 腕关节旋转 wrist_rotate | rad |
| 6 | J07 | 爪夹 gripper | m |

帧索引 t 从 0 到 3149，采样频率为 30 Hz。0–2049 为固体称量的右臂 action，2050–3149 为液体称量的左臂 action。液体段内帧号等于 t - 2050。采样时间为 t / 30 秒，整段视频时长为 105 秒。

例如，本批第一个样本若为原始第 40 条，则 samples.csv 的 SAMPLE 01、plots/sample_001.png 与 results/episode_000040.json 对应同一条数据。样本顺序以 batch_summary.json 的 sample_ids 和 samples.csv 为准。

逐维指标按以下公式计算，其中 ref 是参考 action，pred 是 prediction，T = 3150。

```text
rmse[j] = sqrt(sum((pred[j][t] - ref[j][t])^2 for t in 0..3149) / T)
overall = sqrt(sum(rmse[j]^2 for j in 0..5) / 6)
```

results JSON 保存模型 action 和误差指标。参考轨迹来自对应编号的原始 Parquet 数据，参考视频也来自原始数据集。本次包中包含对比 PNG，原始 Parquet 和视频需另行保留。

## 成功率和文件核验

成功率 = 已确认成功的条目数 / 本批固定条目总数。尚未确认的评定不会计入成功数。batch_summary.json 中 success_rate 是 0–1 的比例，界面按百分比显示。

运行记录所需的信息分布在汇总、评定、备注和异常文件中，因此导出包无需另附“运行记录.json”。服务的自动保存缓存独立保留在内部缓存目录，导出文件夹是点击导出时的固定快照。

导出时验证 PNG 能正确解码、清单中的文件 SHA-256 一致以及 ZIP 完整性。batch_summary.json 自身的哈希和 ZIP 哈希由服务保留用于退出前核验。修改评定、备注或异常记录后，应重新导出并使用新快照。
